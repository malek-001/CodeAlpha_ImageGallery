# Vistara Gallery — CodeAlpha Internship

A responsive frontend image gallery built with HTML, CSS and JavaScript.

## Features

- Responsive 3-column / 2-column / 1-column layout
- Nature, City and Travel filters
- Hover animations and image overlays
- Full-screen lightbox
- Previous / Next navigation
- Keyboard controls
- Escape-to-close support
- Photo counter
- Mobile responsive design
- Lazy-loaded images

## Run locally

Open `index.html` in a browser.

## GitHub repository name

Use:

`CodeAlpha_ImageGallery`

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)

## Note

The demo currently uses remote Unsplash image URLs. For a fully offline/self-contained submission, download your preferred images into an `images` folder and replace the image `src` URLs in `index.html`.
